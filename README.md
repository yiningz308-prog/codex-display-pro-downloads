# Codex Display Pro Downloads

这是 Codex Display Pro 的公开下载仓库，只包含安装脚本、已构建的 macOS 应用压缩包和 SHA-256 校验文件。

源码仓库保持私有。普通用户不需要 GitHub 账号或 GitHub CLI，直接运行：

```bash
curl -fsSL https://raw.githubusercontent.com/yiningz308-prog/codex-display-pro-downloads/main/install.sh | bash
```

当前版本：**1.9.9**

要求：macOS 13 或更高版本、Apple Silicon。
